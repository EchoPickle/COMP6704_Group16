# 分阶段实现方案与核验

## 第一阶段：建立数学约定

使用最大化对偶、`f=Xw+b`、标签 `{-1,+1}`、总和 hinge loss。参数 C、margin 容差、扫描上限和随机种子都由用户指定。`docs/mathematics.md` 推导公式，并明确边界容差不等同于停止容差。

## 第二阶段：构造优化组件

| 组件 | 职责 | 主要测试 |
|---|---|---|
| `pair_bounds` | 两个盒约束和等式约束相交得到一维区间 | 同/异标签、边界初值、区间内多点可行性 |
| `_candidate_indices` | 自由变量优先、误差差值排序、全体回退 | 覆盖所有 j、排除自身、自由集合优先 |
| `_take_step` | 解析子问题、端点、伙伴更新、偏置、缓存 | 解析解、等式保持、对偶增益、极小/零曲率 |
| `bias_interval` | 全体 KKT 的偏置上下界 | 无自由支持向量、反向区间、最坏残差最小化 |
| `kkt_residuals` | 三类 alpha 状态的 margin-KKT | 每一分支的手工残差 |
| `objectives` | 原始/对偶目标和间隙 | 已知解析解的强对偶 |

优化器保留训练输入副本、alpha、b、Gram 矩阵和误差向量。每次成对更新只增量维护 alpha,b,E；每次扫描结束重新计算 w,E、校准 b，并记录诊断。这样把快速局部状态和可信全局检查放在清楚的两个边界。

## 第三阶段：外层循环与模型接口

完整扫描与自由集合扫描交替，连续自由集合扫描最多五次，防止边界变量被持续极小更新饿死；每次扫描内部至多对每个被选中的 i 接受一次成功更新。停止判据由全样本诊断决定。迭代上限与数值停滞都警告；返回当前模型让使用者能够审阅残差，而不假装最优。

`fit` 每次从零重置；`decision_function` 直接使用 w,b；`predict` 对零分数选择 +1。拒绝非二分类标签、NaN、无穷、复数、空特征、尺寸不匹配和无效参数。预测前必须训练。

`tests/test_solver.py` 检查每次扫描的对偶可行性与目标、独立计算最终 KKT，并覆盖重复/冲突样本、秩亏、零特征列、极小 C、无自由支持向量、随机复现、重新拟合和未收敛状态。独立子进程禁止导入 sklearn/scipy，确认求解不依赖参考优化器。

## 第四阶段：独立参考与实验

`tests/test_reference.py` 对多种 C 和数据种子比较 SVC 的目标、w,b、独立新样本分数及预测。SVC 使用更严格的容差并关闭 shrinking，方便核验；不会要求非唯一 alpha 逐项相同。

实验独立使用 300 个二维样本，分层按 70%/30% 划分；只用训练集拟合缩放。所有输入和分组保存到 CSV。边界画在缩放坐标中，训练与测试使用不同标记，支持向量加空心圈。决策边界与参考边界可直接对比，另画真实逐次扫描目标与 KKT 曲线。

图形契约：用于回答“该实现是否在此合成数据上达到指定最优性精度，并复现参考决策函数”；边界面板提供结果与参考比较，目标面板展示优化推进，KKT 面板展示停止依据。使用 Python/Matplotlib、白底、蓝/橙类别、深色主方法、灰色参考，输出可编辑 SVG/PDF 与 PNG 预览。所有数据均为明确标记的合成数据，单次实验不附加无根据的统计推断。

## 复杂度与后续扩展

Gram 矩阵 `O(n²)` 内存，误差缓存 `O(n)`；每次成功更新 `O(n)`，每次候选排序 `O(n log n)`，穷举回退最坏尝试 `O(n)` 个伙伴。刷新线性分数约 `O(nd)`。这里有意保留完整诊断与透明流程。

后续可在不改变子问题推导的前提下扩展核接口、缓存、工作集策略、缩放器或类别权重。非线性核下 eta 不能再用输入空间距离；不定核下 eta 可能非正，需相应处理，不能直接复用此线性特化实现。
